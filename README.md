# SEREIN

Luxury hospitality loyalty platform — Luxury Editorial / Modern Noir.

## Product surfaces
- Marketing website
- Guest loyalty portal
- Restaurant owner dashboard
- SEREIN company administration

## Brand tokens
- Noir Forest `#101310`
- Deep Olive `#1B211D`
- Muted Brass `#B49A70`
- Warm Ivory `#F0EDE4`
- Muted Sage `#A8B0A0`
- Fine Border `#343A33`

The first release is a front-end prototype. Authentication, persisted loyalty transactions, billing, and tenant isolation must be implemented and tested before production use.
